# LomoXSoft.github.io

Web de portfolio de **LomoXSoft**: software libre y juegos pixel art (LomoXGames).
*Software libre para todos. Y algún que otro píxel.*

Se publica con GitHub Pages en <https://lomoxsoft.github.io> y la división de videojuegos **LomoXGames** en <https://lomoxsoft.github.io/LomoXGames/>.

Página estática: `index.html` + `estilo.css` (y `LomoXGames/index.html` + `LomoXGames/estilo.css`), sin dependencias externas ni paso de compilación.
Para verla en local: `python3 -m http.server` y abrir <http://localhost:8000>.
